# Catholic Projects Community

**A directory of work and instructions extending the value of MinistryPlatform, often beginning with Catholic organization use cases in mind.**

We are Catholic dioceses, parishes and schools that use [MinistryPlatform](https://www.ministryplatform.com/) (MP). What we build here is shared so that others, Catholic or not, can use it, adapt it, and improve it. Much of it starts from work by the wider [MinistryPlatform Community](https://github.com/MinistryPlatform-Community).

## Projects

- **[MPNext](https://github.com/Catholic-Projects-Community/MPNext):** a Next.js starter app with MP sign-in and the MP REST API. The base the other apps are built on.
- **[MPNext-Tools](https://github.com/Catholic-Projects-Community/MPNext-Tools):** MP page tools built on MPNext. Each organization runs its own copy.
- **MPNext-Tools-SF:** a version of MPNext-Tools for Catholic dioceses, built for the Diocese of Sioux Falls and being made portable to other dioceses, starting with the Archdiocese of Omaha. It adds the Diocese Directory and per-organization settings and themes, kept in each MP database. The code is private for now; the [guides](https://github.com/Catholic-Projects-Community/.github/tree/main/guides/mpnext-tools-sf) are public.
- **[MPNext-Widgets](https://github.com/Catholic-Projects-Community/MPNext-Widgets):** embeddable web-component widgets backed by MP.
- **[MPReports](https://github.com/Catholic-Projects-Community/MPReports):** SSRS reports and stored procedures, with step-by-step install instructions.
- **[MCP-Resources](https://github.com/Catholic-Projects-Community/MCP-Resources):** recipes and live artifacts for the [MinistryPlatform MCP Server](https://ai.ministryplatform.com).
- **[Community-Resources](https://github.com/Catholic-Projects-Community/Community-Resources):** SQL and n8n snippets from the MP community.

## A note on copies

Most of these projects are templates: you copy them and run your own. Fixes made here do **not** reach your copy automatically, so check each project's security notes and pull in updates.
